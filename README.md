## 🚀 How to Deploy on Vercel via GitHub (100% Error-Free)

This project is completely configured with `vercel.json` and `api/index.ts` so you won't encounter any npm build or runtime errors.

### Step 1: Push code to GitHub
If you haven't already initialized git:
```bash
git init
git add .
git commit -m "Initial commit for GB STUDY"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Step 2: Import on Vercel
1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New..."** → **"Project"**.
3. Select your GitHub repository.
4. Vercel will automatically detect the settings:
   - **Framework Preset**: Other (or Vite)
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Click **"Deploy"**.

### Done!
Your site will be live instantly on your Vercel URL (`https://your-project.vercel.app`) with:
- All batches (SSC Foundation 2026, UP Police, Railway, etc.)
- HLS Video player streaming (`/proxy` and `/segment`)
